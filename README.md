# 引力之心 · Gravity Heart

星尘汇成爱心，散开时是你的名字；再把整片星河，开成一朵玫瑰。

一个可以自己填写名字、照片和心事的表白网页。**不需要安装 Python、Node.js 或任何项目依赖。**

[在线体验](https://yanami-sec.github.io/heart/) · [下载免安装版](https://github.com/yanami-sec/gravity-heart/releases/latest/download/gravity-heart-offline.zip) · [博客备用下载](https://yanami-sec.github.io/heart/gravity-heart-offline.zip)

![星尘爱心](docs/images/heart.jpg)

## 直接使用

**电脑**

1. 下载上面的免安装压缩包并解压。
2. 双击里面的 `index.html`，用 Edge、Chrome 或 Firefox 打开。
3. 点右上角「写给某个人」，填写名字、心事和心动碎片，也可以加入照片。
4. 点「保存成网页」，生成包含这些内容的独立 HTML，再亲手发给对方。

从 GitHub 下载整个源码 ZIP 也可以：解压后双击根目录的 `index.html`。Windows 还可以双击「启动本地.bat」。两种方式都不需要启动服务器。

如果 HTML 默认在编辑器里打开，右键文件，选择「打开方式 → 浏览器」。请先解压，避免在压缩包预览里打开。

**手机**

安卓和 iPhone 直接用浏览器打开 [在线体验](https://yanami-sec.github.io/heart/)。部分文件管理器、聊天软件会把下载的 HTML 当作预览文件，这种情况使用在线地址即可。

## 这里藏了什么

- 两股星尘从远处涌来，汇成一颗立体爱心；移动鼠标旋转，手机支持触碰互动。
- 按住爱心或空格压缩，松手后星光依次组成名字、告白短句，再回到爱心。
- 100 个优点词被小爱心与星尘包裹，沿轨道环绕；可以点开阅读，也可以一次看完整清单。
- 心动碎片里能写小事、放照片，没有解锁门槛。
- 「让心意开花」：32 片星尘花瓣依次展开，支持拖动旋转、俯视、双击回正和再次绽放，星轨与蝴蝶围绕花朵流动。
- 「流星接力」：流星依次点亮照片，最后抵达名字，支持暂停、跳过和返回。
- 一封可以自己写的信；读完后，信纸化作星光回到爱心。
- 对方可以写回信，复制文字或保存成 PNG 图片。
- 玫瑰、蓝紫、熔金三种配色，以及默认关闭的合成心跳音效。

## 改成你们的故事

右上角「写给某个人」可以修改：收信人、落款、正文、结尾、优点词、三至五颗心动碎片及其照片，还有流星照片的配文。

点击「保存成网页」，文字、照片、字体与动画会保存在同一个 HTML 文件里，导出的网页可以离线打开。内容在浏览器内处理，不会上传到服务器；项目不附带商业歌曲。

演示名字是 `yanami`，内容都是示例，可以按对方真实的特点替换。流星使用的 11 张示例插画位于 `assets/journey/`，开发时可替换素材后通过 `tools/embed-gallery.py` 重新嵌入。

## 源码与开发

- `index.html`：双击打开的入口。
- `dist/index.html`：可直接运行、离线使用的完整网页。
- `assets/`：字体、示例图片、蝴蝶素材及说明。
- `docs/images/`：项目截图。
- `tools/`：编辑、嵌入素材、打包和本地开发工具。

运行页面不依赖服务器、构建工具、远程字体、CDN 或外部模型，所有运行素材均已嵌入 `dist/index.html`。可放到普通静态站点或子目录中使用。

开发者如需 HTTP 本地预览，可安装 Node.js 后运行 `npm start`，地址为 `http://127.0.0.1:8791/`。这只是可选的开发方式，使用者无需安装。

重新制作免安装压缩包：`python tools/package-offline.py`。打包工具仅用于开发，压缩包内不包含 Python，打开网页也不需要 Python。
